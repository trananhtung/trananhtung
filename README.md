---

I take small, well-loved JavaScript packages and rewrite them in Rust. Same
behavior, zero dependencies, `no_std` where it fits. Nobody asked me to. I just
think a `decamelize` that pulls in zero crates should exist.

The rest of my time goes to Vietnamese language tools (a Telex/VNI input method,
a 31k-line bilingual quote library) and small tools around AI coding agents.

Đà Nẵng. Shipping since 2017. More repos than free evenings.

> 🇻🇳 Mình thích viết mấy thư viện nhỏ mà chạy đúng. Sạch, không phụ thuộc lung tung, test kỹ. Vậy thôi.

**How I work**

- Zero dependencies by default. A crate gets added only when I truly can't avoid it.
- Ports keep the original API and edge cases, with its test suite translated over.
- Yes, the repo count is real. No, most of them aren't dead.
